# files/ — 자료실 공개 파일

관리자 화면 **현장·공개 → 자료실**에서 공개하는 파일을 두는 곳입니다.
GitHub Pages가 이 폴더를 그대로 서빙하므로, 여기 올린 파일은 `https://<사이트>/files/<파일명>`으로 받을 수 있습니다.

## ⚠ 올리기 전에

이 저장소는 **public**입니다. 여기 올린 파일은 자료실 목록에 등록하지 않아도,
파일명을 알거나 GitHub에서 폴더를 열어보면 누구나 받을 수 있습니다.
**되돌릴 수도 없습니다** — 한 번 커밋한 파일은 나중에 지워도 git 이력에 남습니다.

그러므로 아래는 올리지 마십시오.

- 개인정보가 담긴 파일(성명·연락처·사번 등)
- 대외 공개용이 아닌 내부 문서·보안 문서
- 강사 실명 대응표, 설정값, 계정 정보

## 올리는 방법

평소에는 **관리자 화면 → 현장·공개 → 자료실**에서 파일을 바로 올리면 됩니다.
올린 파일은 이 폴더에 커밋되고, 1~2분 뒤 배포가 끝나면 받을 수 있습니다.
(파일 하나당 8MB, 문서·이미지·압축만 가능)

**8MB를 넘는 파일**은 GitHub에서 직접 올립니다.

1. GitHub 저장소에서 이 폴더를 열고 **Add file → Upload files**
2. 파일명은 **영문·숫자·하이픈** 권장 (한글·공백은 주소가 퍼센트 인코딩되어 다루기 번거롭습니다)
3. 커밋하면 1~2분 뒤 배포 완료
4. 관리자 화면 **자료실**의 '올라간 파일'에서 **새로고침** → **목록에 추가**

## 올릴 수 없는 형식

`.html` · `.js` · `.svg` 등은 함수에서 막습니다. 자료실은 관리자 화면과 **같은 도메인**이라,
이런 파일을 올리면 그 안의 스크립트가 관리자 세션이 있는 오리진에서 실행될 수 있습니다.

## 용량

- 파일 하나당 **100MB** 미만 (GitHub 제한)
- 저장소 전체가 커지면 clone·배포가 느려집니다. 총합 **1GB 이내**를 권장합니다.
- 영상처럼 큰 파일은 여기 두지 말고 별도 서비스를 쓰세요.

## 지울 때

자료 목록에서 지우는 것과 파일을 지우는 것은 **다릅니다.**

- **목록에서 삭제** — 공개 페이지에 안 보이게만 합니다. 파일은 남아 주소로 받을 수 있습니다.
- **파일 삭제** — 관리자 화면 '올라간 파일'의 **파일 삭제** 버튼. 주소로도 받을 수 없게 됩니다.

단, 위에 적었듯 **git 이력에는 남습니다.** 올리면 안 될 파일을 올렸다면 삭제만으로는
부족하니 알려 주세요(이력까지 지우려면 저장소를 다시 써야 합니다).
