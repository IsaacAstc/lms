📊 게임 기록

게임 종료 시 자동 저장됩니다(닉네임·점수·문항별 정오답만 — 단답형 응답 원문은 저장하지 않음). 기록은 계속 보관되며 상세 화면에서 삭제할 수 있습니다.

이미지 파일은 자동 압축해 퀴즈에 내장됩니다. 동영상 파일은 저장소 media/ 폴더로 업로드됩니다(공개 저장소 — 공개 가능한 영상만 · 배포 1~2분 후 재생 가능). 유튜브/mp4 URL도 사용할 수 있습니다.
🔑 동영상 업로드용 GitHub 토큰 발급 방법
  1. github.com 로그인 → 우측 상단 프로필 → Settings
  2. 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Token name 자유 입력, Expiration은 원하는 기간(예: 1년)
  4. Repository access: Only select repositories → IsaacAstc/lms 선택
  5. Permissions → Repository permissions → Contents: Read and write만 켜기 (나머지는 No access)
  6. Generate token → 표시된 토큰(ghp_… 또는 github_pat_…)을 복사
  7. 여기서 🎬 동영상 파일 버튼을 누르면 나오는 입력창에 붙여넣기 — 이 브라우저에만 저장됩니다
토큰이 만료되었거나 바꾸고 싶으면 위 토큰 재설정을 누른 뒤 다시 업로드하세요.
