# 시연영상 리허설 체크리스트

[시연영상 대본](시연영상_대본.md)의 장면 순서대로 데모 기관에서 한 번씩 실제로 실행해 보며 확인한다.
먼저 대본의 **촬영 준비 체크리스트**를 모두 마친 뒤 시작한다.

- 각 장면: ✅ 통과 기준을 확인하고, 걸린 시간을 적고, 막힌 점은 '메모'에 적는다.
- 막힌 점이 있으면 장면 번호와 화면 캡처를 함께 전달하면 바로 수정한다.

---

## 리허설 전 주의 (기기별 1회 제한)
- **설문(장면 4)**: 같은 기기·같은 차수는 1회만 응답된다. 리허설과 촬영에 다른 기기나 시크릿 창을 쓴다.
- **히어로 미션(장면 10)**: 기기당 행사별 **2회**까지만 참여된다. 리허설용 행사와 촬영용 행사를 따로 만들거나, 촬영 휴대폰으로는 리허설하지 않는다.
- **묶음 신청(장면 2-1)**: 신청할 때마다 데모 과정의 잔여석이 줄고 접수 메일이 실제로 발송된다. 리허설 뒤 관리자 화면에서 반려 처리해 잔여석을 되돌린다.
- **AI 기능**: 계정당 시간당 호출 상한(기본 40회)과 주간 브리핑 즉시 발송(하루 3회) 제한이 있다. 리허설에서 반복 호출을 아낀다.
- **OpenRouter 무료 모델 하루 한도**: 누적 충전액이 10달러 미만이면 무료 모델은 **하루 50회**까지다(넘으면 429로 실패하고, 대체 모델도 같은 계정이라 함께 막힌다). 리허설과 촬영을 **다른 날로 나누거나**, 누적 10달러를 채워 하루 1,000회로 늘린다(무료 모델은 0원이라 충전액은 줄지 않는다). 무료 모델만 쓰면 잔액 부족 안내 메일은 무시해도 된다.

## 장면별 확인

| 장면 | ✅ 통과 기준 | 시간 | 메모 |
|---|---|---|---|
| 1. 문제와 해법 | 로그인 후 상단 메뉴 전체가 한 화면에 보인다. 기관 선택이 **데모 기관**이다 | | |
| 2. 시간표·중복 검증 | 커리큘럼 불러오기로 시간표가 한 번에 채워진다. 강사를 바꿔 저장할 때 **중복 경고**가 뜬다 | | |
| 2-1. 묶음 신청 | 담기 2개 → 하단 바 → 과정별 인원·총 인원 → 발송 → **과정별 접수번호 표**. 접수 메일 1통 수신. 관리자 접수 이력에 **'묶음 … · 2개'** 표시 | | |
| 3. 강사료 | 월 선택 시 강사별 금액·여비가 계산된다. 인쇄(PDF) 미리보기가 한 장에 맞는다 | | |
| 4. 익명 설문 | QR로 휴대폰 진입 → **개인정보 안내 문구** 보임 → 5점 척도 응답 → 제출 완료 화면 | | |
| 5. AI 주관식 분석 | 결과 카드에 **가림 N건**·분류·시사점·반영계획이 나온다. ○○○로 가려진 문장이 있다. 분류 적용이 된다 | | |
| 6. 보고서·AI 총평 | 요약표·세부표·운영결과·**소요경비**까지 나온다. AI 총평에 **'숫자 대조 통과'** 표시. 보고서 반영 → PDF | | |
| 7. 개선 효과 | AI 조치 추출 → 등록 → '완료' 변경 → 효과 칸(전 3개월 → 후 3개월)에 수치가 나온다 | | |
| 7-1. AI 비서·브리핑 | 질문 1에 **'🔎 정원 점검'**, 질문 2에 '조회 결과 보기'가 펼쳐진다. 브리핑 미리보기가 나온다 | | |
| 8. 공문 초안 | 소속기관별 본문에 강사별 일정이 정리된다. 강사 실명 자리는 **○○○** | | |
| 9. 퀴즈 | 휴대폰 2대 QR 입장 → 문제·정답·순위 → 최종 순위. AI 문항 초안이 과정 기준으로 나온다. 게임 기록에서 **AI 학습 진단** 카드가 나온다 | | |
| 10. 히어로 미션 | (마스터 계정) 미션 4 AI 단어 초안 → 배치 확인. 휴대폰: 미션 1·4·5 진행, **미션 5 소리** 남, 인증서 제목 = 행사 문구, 인증서 저장 후 **완료 안내**, 실시간 순위 반영 | | |
| 11. 모델 교체 | 3개 모델 각각 '연결 정상'. 실행 기록에 모델별 이력과 **"대체"** 표시가 있다 | | |
| 12. 마무리 | 휴대폰에서 공개 현황 보드가 카드형으로 깔끔하게 보인다 | | |
| **합계** | 목표 약 7분(편집 전 실제 진행은 10~12분 예상) | | |

## 장면별 미리 준비·막힐 때

- **2. 시간표**: 같은 시간대에 다른 차수 강의가 있는 강사를 미리 골라 둔다(모의데이터의 같은 날 차수 2개).
- **5·6·7. AI 결과**: 무료 모델은 혼잡(429)으로 실패할 수 있다. 실패하면 모델을 바꿔 다시 실행하거나, 촬영은 유료 모델로 한다. 응답 대기는 편집에서 자른다.
- **6. 숫자 대조 경고**가 뜨면: 다시 생성하거나 다른 모델로 실행한다(경고가 뜨는 것도 기능 소개로 쓸 수 있다).
- **8. 공문**: 출강 강사가 있는 달·소속기관을 미리 확인해 둔다. 일정이 없으면 본문이 비어 보인다.
- **9. 퀴즈 진단**: 게임을 한 판 이상 끝내야 기록이 생긴다. 리허설에서 한 판 진행해 두면 촬영 때 진단 장면에 그대로 쓴다.
- **10. 히어로 미션**: AI 단어 초안 버튼은 **마스터 계정**에서만 보인다. 인증서 저장은 안드로이드=다운로드, 아이폰=공유 창 '이미지 저장', 카카오톡 앱 안=길게 눌러 저장. 촬영은 일반 브라우저(크롬·사파리)로 연다.
- **11. "대체" 표시 만들기**: 실행 기록에 대체 이력이 없으면, 촬영 직전에 기본 모델의 모델명을 일부러 틀리게 바꿔 **AI 비서에 질문을 한 번** 한다 → 다른 모델로 대체되어 실행 기록에 "대체: (모델)"이 남는다(대체 표시는 AI 비서 실행 기록에 나온다). **촬영 후 모델명을 반드시 원래대로 되돌린다.**
