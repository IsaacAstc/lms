# 시연영상 대본 — 항공보안 교육 운영관리 시스템 (약 7분)

- 화면: 데모 기관(가상 데이터)으로 로그인한 PC 화면 녹화(1920×1080), 모바일 장면 1개
- 표기: **[화면]** 보여 줄 것 · **[내레이션]** 읽을 말 · ⏱ 누적 시간
- 촬영 전 준비: 모의데이터 생성, 소요경비 탭 한 번 저장, AI 연결 3종 등록·테스트 통과, 샘플 퀴즈 추가, 히어로 미션 행사(미션 구성 1,2,3,4,5) 생성, 휴대폰 2대(참가자용), 브라우저 확대 110%, 알림 끄기

---

## 장면 1. 문제와 해법 (0:00 ~ 0:30)
**[화면]** 제목 카드 → 로그인 화면 → 로그인 후 상단 메뉴 전체
**[내레이션]**
> 항공보안교육훈련센터는 연간 수백 개 차수를 운영하면서 시간표, 강사료, 설문, 결과 보고서를 엑셀과 문서로 따로 관리해 왔습니다.
> 이 시스템은 이 업무를 하나의 웹 화면으로 묶고, 생성형 AI를 붙여 설문 분석과 보고서·공문 작성을 돕습니다.
> 교육생 개인정보는 처리하지 않도록 설계했고, AI 모델은 설정만 바꾸면 교체할 수 있습니다.

## 장면 2. 시간표 입력과 중복 검증 (0:30 ~ 1:05)
**[화면]** 교육 운영 → 차수·시간표 → 차수 선택 → 커리큘럼 불러오기 → 한 과목의 강사를 같은 시간 다른 차수 강사로 바꿔 저장 → 중복 경고 표시
**[내레이션]**
> 차수를 고르고 커리큘럼을 불러오면 시간표가 한 번에 만들어집니다.
> 같은 시간에 강사나 강의실이 겹치면 저장 전에 바로 경고해 일정 충돌을 막습니다.

## 장면 3. 강사료 자동 계산 (1:05 ~ 1:30)
**[화면]** 강사료·경비 → 강사료·집계 → 월 선택 → 강사별 금액·여비 → 인쇄(PDF) 미리보기
**[내레이션]**
> 시간표가 확정되면 강사 유형별 단가와 월 상한, 소속지별 여비가 자동 적용돼 강사료가 계산됩니다. 결재용 집계표는 바로 PDF로 출력합니다.

## 장면 4. 익명 설문 (1:30 ~ 1:55)
**[화면]** 설문 관리의 QR → 휴대폰 화면(설문 시작 안내 문구 확대) → 5점 척도 응답 → 제출
**[내레이션]**
> 교육생은 강의실 QR로 로그인 없이 응답합니다. 이름·연락처·IP를 저장하지 않는 완전 익명이며, 응답은 100점으로 환산해 집계됩니다.

## 장면 5. AI 주관식 분석 (1:55 ~ 2:40)
**[화면]** 설문 → 주관식 원문 → 월 선택 → 모델 선택 → AI 분석 → 결과 카드(가림 N건, 분류, 시사점·반영계획) → 이름이 ○○○로 가려진 문장 확대 → 분류 적용
**[내레이션]**
> 수백 건의 주관식 의견을 AI가 분류하고, 시사점과 피드백 반영계획 초안을 씁니다.
> 의견에 이름이나 연락처가 섞여 있어도 서버가 먼저 가린 뒤에만 AI로 보냅니다.
> 분류는 정해진 목록 안에서만 허용하고, 적용 여부는 담당자가 결정합니다.

## 장면 6. 운영 결과 보고서와 AI 총평 (2:40 ~ 3:25)
**[화면]** 통계·보고서 → 운영 보고서 → 월 선택 → 보고서 생성(요약표·세부표·운영결과·소요경비 스크롤) → AI 총평 → "숫자 대조 통과" 표시 확대 → 보고서에 반영 → 인쇄(PDF)
**[내레이션]**
> 매달 작성하던 운영 결과 보고서가 데이터로 자동 완성됩니다.
> 총평은 AI가 쓰지만, 숫자는 시스템이 계산해 넘기고 초안 속 숫자를 다시 대조해 AI가 지어낸 수치가 있으면 경고합니다.

## 장면 7. 개선 효과 추적 (3:25 ~ 3:55)
**[화면]** 개선 추적 → AI로 조치 추출 → 선택 등록 → 한 조치를 '완료'로 변경 → 효과 칸(전 3개월 → 후 3개월)
**[내레이션]**
> 반영계획에서 개선 조치를 뽑아 등록하고, 조치를 완료하면 같은 분류의 불만족 의견이 전후 3개월 사이 얼마나 줄었는지 시스템이 계산합니다.
> 피드백 수집부터 개선 확인까지 한 바퀴가 닫힙니다.

## 장면 7-1. AI 운영 비서·주간 브리핑 (3:55 ~ 4:30)
**[화면]** 통계·보고서 → AI 비서 → 예시 질문 "다음 달 신청이 저조하거나 마감 임박한 차수는?" → 답변 위 '🔎 정원 점검' 표시 → 이어서 "이번 달 시간표에 겹치는 일정 있어?" → '조회 결과 보기' 펼침
**[내레이션]**
> 담당자는 메뉴를 찾아다니지 않고 말로 묻습니다. AI는 시스템의 정해진 조회 기능 중 필요한 것을 골라 쓰고,
> 계산은 시스템이 합니다. 어떤 조회를 했는지와 원자료가 함께 보여 답을 바로 검증할 수 있습니다.

**[화면 이어서]** 설정 → 주간 AI 운영 브리핑 → 미리보기
**[내레이션]**
> 매주 월요일 아침에는 AI가 먼저 이번 주 일정과 먼저 챙길 일을 메일로 보내 줍니다.

## 장면 8. 공문 초안 (4:30 ~ 5:00)
**[화면]** 공문 초안 → 출강 요청 공문 → 월·소속기관 선택 → AI 초안 작성 → 강사별 일정이 정리된 본문, ○○○ 표기 확대 → 복사
**[내레이션]**
> 출강 요청 공문은 그 달 일정을 강사 소속기관별로 묶어 기관당 한 건씩 작성합니다.
> 강사 실명은 AI에 보내지 않고, 자료에 없는 내용은 빈칸으로 남겨 담당자가 채우게 합니다.

## 장면 9. 교육생 참여 — 퀴즈 배틀·AI 출제·학습 진단 (5:00 ~ 5:35)
**[화면]** 상단 '퀴즈' → 샘플 퀴즈 진행 → PIN·QR 화면 → 휴대폰 2대로 QR 입장 → 문제·정답 공개·순위 → 최종 순위
**[내레이션]**
> 수업 중에는 실시간 퀴즈로 참여를 끌어냅니다. 교육생은 QR로 로그인 없이 닉네임만 넣고 들어오고,
> 정답과 순위가 바로 화면에 나옵니다.

**[화면 이어서]** 퀴즈 편집기 '🤖 AI 문항 초안'(과정 선택 → 초안 → 골라 추가) → 게임 기록 → '🧠 AI 학습 진단'
**[내레이션]**
> 문항은 과정 커리큘럼을 근거로 AI가 초안을 만들고, 강사가 골라 다듬습니다. 게임이 끝나면 AI가 문항별 정답률과
> 오답 분포를 보고 취약 개념과 다음 수업에서 짚을 점을 정리합니다. 출제부터 진단, 보완까지 하나로 이어집니다.

## 장면 10. 교육생 참여 — 항공보안 히어로 미션 (5:35 ~ 6:15)
**[화면]** 관리자: 행사 카드(미션 구성·인증서 문구) → 행사 QR → 휴대폰: 닉네임 입장 → 미션 1 위험물 찾기(짧게) → 미션 4 낱말 퍼즐(정답 입력) → 미션 5 공항 하늘 방어(위험물 압수·안전물품 감점·수상한 드론) → 인증서 화면(행사명 제목) → 실시간 순위
**[내레이션]**
> 진로박람회 같은 현장 행사에는 '항공보안 히어로 미션'을 운영합니다. 위험물 찾기부터 낱말 퍼즐,
> 공항 하늘 방어 게임까지 다섯 가지 미션으로 보안검색요원·폭발물처리요원 같은 공항 직업을 체험합니다.
> 개인정보 없이 닉네임만 쓰고, 행사마다 미션 구성과 인증서 문구를 바꿀 수 있으며, 점수는 실시간 순위로 집계됩니다.

## 장면 11. 모델 교체와 자동 대체 (6:15 ~ 6:40)
**[화면]** 설정 → AI 연결 → 3개 모델 행 → 각각 테스트(연결 정상) → 주관식 원문에서 모델을 바꿔 다시 실행 → 실행 기록에 모델별 이력 → '모델 자동 대체' 체크박스와 실행 기록의 "대체" 표시
**[내레이션]**
> 모든 AI 기능은 표준 규격 하나로 호출합니다. 접속 주소와 모델명만 바꾸면 Gemma, GPT-OSS, Llama 같은 다른 모델로 교체되고, 기관 내부에 설치한 모델로도 같은 방식으로 전환할 수 있습니다.
> 기본 모델이 혼잡하거나 장애가 나면 등록된 다른 모델로 자동으로 넘어가, 업무가 멈추지 않습니다.

## 장면 12. 마무리 (6:40 ~ 7:00)
**[화면]** 공개 현황 보드(모바일) → 제목 카드(핵심 3줄)
**[내레이션]**
> 정리하면, 흩어진 교육 운영 업무를 하나로 묶고, AI는 분석과 문서 작성을 돕되 수치와 판단은 데이터와 사람이 책임지는 구조입니다.
> 개인정보는 최소화하고, 모델은 언제든 바꿀 수 있습니다.

**[마지막 카드 문구]**
1. 교육 운영 전 과정 통합 — 시간표·강사료·설문·보고서, 수업·현장 참여(퀴즈·히어로 미션)
2. AI는 초안·질의·브리핑·진단, 수치·판단은 데이터와 사람 — 가림 처리·숫자 대조
3. 모델 비종속·자동 대체 — 설정만으로 외부·내부 모델 교체, 장애 시 자동 전환

### 촬영 팁
- AI 응답 대기(수 초~수십 초)는 편집으로 잘라내고 "AI 작성 중…" 표시만 1초 남긴다.
- 무료 모델은 429(혼잡)가 날 수 있으니 촬영 직전 테스트하고, 필요하면 유료 모델로 촬영한다.
- 가상 데이터임을 첫 화면 자막으로 밝힌다: "시연 화면은 모두 가상 데이터입니다."
- 운영 기관(기본 기관) 화면, 실제 강사 실명, API 키 입력 장면은 찍지 않는다.
- 퀴즈·히어로 미션은 반드시 **데모 기관 바로가기**(주소에 `?org=` 포함)로 열어 데모 데이터로 찍는다.
- 휴대폰 화면은 화면 녹화 후 PC 화면 옆에 작게 붙이면(PIP) 흐름이 잘 보인다. 미션 5는 소리를 켜고 찍는다(아이폰 무음 스위치 확인).
