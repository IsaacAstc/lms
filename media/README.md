# media/ — 퀴즈용 동영상·대용량 미디어

퀴즈 배틀(quiz.html)에서 쓰는 동영상 파일을 두는 폴더.
GitHub Pages로 함께 서빙되어 `https://isaacastc.github.io/lms/media/<파일명>` 주소로 접근한다.

## 올리는 방법
1. (권장) 퀴즈 편집기의 **🎬 동영상 파일 업로드(저장소)** 버튼 — GitHub 토큰을 1회 등록하면
   브라우저에서 바로 업로드된다. 업로드 후 배포(1~2분)가 끝나야 재생 가능.
2. (수동) github.com 저장소 → media 폴더 → `Add file > Upload files` 로 드래그&드롭.

## 주의
- **public 저장소**이므로 공개해도 되는 영상만 올릴 것 (내부 문서·개인정보 포함 영상 금지).
- 파일당 50MB 이하 권장(짧은 클립). 저장소 전체 용량을 위해 불필요해진 파일은 삭제.
- 파일명은 영문·숫자·하이픈 권장 (업로드 기능이 자동 정리함).
